# キタニ水産 納品書サンプル01

キタニ水産はWebで納品書が発行される。店舗確認により、PDFをダウンロードしてアプリへ添付する方式に確定した。

## 入力の流れ

1. iPadでWeb納品書のPDFをダウンロードする。
2. 仕入れ画面のPDF添付から選択する。
3. 原本PDFを指定のDriveフォルダへ年月別に保存する。
4. Google Drive API v3で一時Googleドキュメントへ変換し、本文を取得する。
5. 確認画面で日付・仕入先・伝票番号・品目明細・税額・合計を修正・確認して保存する。
6. 一時ドキュメントは処理後にゴミ箱へ移す。原本PDFのリンクを伝票に保持する。

PDFの文字情報をローカルの読み取り専用処理で抽出できたことを確認済み。GAS上でのDrive変換・抽出精度は今後検証する。
PDF方式の合意であり、他の仕入先の撮影方式はそれぞれの帳票仕様に従う。

## サンプル確認値

対象原本はキタニ水産_納品書_261116.pdf、1ページ。添付のスクリーンショットとも目視照合した。

| 項目 | 値 |
|---|---|
| 発行日 | 2026/11/16 |
| 仕入先 | キタニ水産 |
| 伝票番号 | 00849619 |
| 括弧内の宛先コード | 001457 |
| 税抜合計 | 4,703円 |
| 消費税8% | 376円 |
| 消費税10% | 0円 |
| 税込合計 | 5,079円 |

| 品名 | 数量 | 単位 | 税抜単価 | 明細金額 |
|---|---:|---|---:|---:|
| 鹿児島 カツオ1/4背 | 1.35 | kg | 2,400 | 3,240 |
| 冷アラカブ | 1.33 | kg | 1,100 | 1,463 |

1.35×2400=3240、1.33×1100=1463、3240+1463=4703、4703+376=5079で照合できる。
品名に含まれる1/4背は商品規格として保持する。仕入数量は数量欄から取得する。
印字税額376円を採用し、計算結果376.24で上書きしない。
8%対象の印と税率別集計を照合する。10%税額0円は明示された実績0円として扱う。
既存台帳へは税込5,079円を反映する。

## 重複と確認事項

伝票番号は先頭0を保持した文字列で保存する。
宛先コード001457を伝票番号へ混在させない。
同じPDFの再添付や形式を変えた原本が届いた場合も、仕入先・伝票番号で既存登録の候補を確認して重複計上を防ぐ。
原本は「発行日」のみが印字されている。店舗確認により、発行日を納品日の初期値とする。確認画面では納品日を修正できる。
実OCR、ページ追加時の処理、iPadのPDF選択操作、Drive原本保存はテスト環境で確認する。
